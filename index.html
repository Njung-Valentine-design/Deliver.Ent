Metric quick reference

Delivery — project health. Core win condition.
Stakeholder — executive confidence. Both <35 = game over.
Burnout — team fatigue. Above 70 = delivery impaired.
Reputation — personal brand. Unlocks headhunter offers.
Budget — spend vs allocation. 0 = immediate failure.
Morale — team energy. Low morale reduces all outputs.

About DELIVER.

DELIVER. is a rules-first enterprise project leadership simulation. Every decision changes 9 live metrics. Political intelligence, stakeholder trust, and delivery health all matter. Rise from Associate Project Coordinator to Chief Delivery Officer across 10 levels and 8 industries.

Built with a deterministic rules engine. No AI required. All consequences are calculated by game logic.
