Metric quick reference

Delivery — project health. Core win condition.
Stakeholder — executive confidence. Both <35 = game over.
Burnout — team fatigue. Above 70 = delivery impaired.
Reputation — personal brand. Unlocks headhunter offers.
Budget — spend vs allocation. 0 = immediate failure.
Morale — team energy. Low morale reduces all outputs.
